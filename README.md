# Intermind Agency Website

Static GitHub Pages website for Intermind Agency.

## Structure

- `index.html` – one-page landing page
- `fine-print.html` – consolidated legal notice, privacy policy, and terms
- `assets/css/style.css` – styles
- `assets/js/main.js` – interactive behavior
- `assets/images/` – logo, favicon, abstract visuals and SVG icons
